RELATIONSHIPS

1. SEMESTER → SUBJECT
- One semester can have many subjects.
- Each subject belongs to one semester.

2. SUBJECT → RESOURCE
- One subject can have many resources.
- Each resource belongs to one subject.

3. USER
- A user can be a STUDENT or ADMIN.
- ADMIN can add and manage resources.
- STUDENT can view resources.
